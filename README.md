# Dropzone Actions
This repository contains action bundles for [Dropzone by Aptonic](https://aptonic.com). You are free to download and use these actions in your own Dropzone install.

I use them myself, but they are provided with no warranty or service. They are provided as is and you use them at your own risk.

# Installation

1. Download the `.dzbundle` file.
2. Open the `.dzbundle` file.

The action will be in stalled to Dropzone. You may then add it to a grid and customise its settings.

# Actions

## Rename and Move Files
This action will allow you to move a file to a specified location and rename it at the same time (via a pop up). Holding down *Option* while you do this will copy rather than moving the file.

- [Download](https://github.com/sylumer/dropzone-actions/raw/refs/heads/main/Rename%20and%20Move%20Files.dzbundle)

## Tinification
This is a modified version of the standard *Tinify* action provided by Aptonic. This version rather than creating a new file alongside the original replaces the original.

- [Download](https://github.com/sylumer/dropzone-actions/raw/refs/heads/main/Tinification.dzbundle)
